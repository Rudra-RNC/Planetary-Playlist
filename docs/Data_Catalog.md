# NASA EIC Data Catalog

The current ten-track playlist uses still frames from NASA Scientific Visualization Studio pages and the EIC API catalog entry. The local files are compressed copies of the cited NASA preview frames; the app maps visible pixels, not raw measurements. The API-derived Wind Atlas track is explicitly image-based and does not claim to encode numerical wind vectors.

The official [EIC gallery](https://svs.gsfc.nasa.gov/gallery/earth-information-center/) contains a broader mix of dashboards, videos, beauty pieces, and daily visualizations. This project curates ten still-frame experiences rather than claiming to represent every EIC item.
