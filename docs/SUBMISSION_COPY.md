# NASA Space Apps Submission Copy

## Summary

Planetary Playlist is an accessible Earth Jukebox that lets people hear NASA Earth Information Center visualizations. Choose one of six bundled NASA frames and the playhead sweeps across it while a browser-based sonification engine translates visible color, brightness, contrast, and position into a live, scale-locked soundscape. The experience pairs scientific descriptions and source credits with keyboard controls, screen-reader labels, live quarter-by-quarter narration, reduced-motion support, and a visual sound key. It is important because Earth science is often presented only through sight; Planetary Playlist lets blind, low-vision, and sighted audiences explore the same Earth stories through sound without sacrificing scientific context.

## Project details

Each frame is analysed once into a 96 × 32 grid. Salient cells become deterministic note events: row maps to pitch inside an author-selected scale, column maps to time and stereo position, visible hue selects a synth voice, and brightness/salience affect loudness and density. Tone.js schedules the events through a low-pass filter, algorithmic reverb, compressor, limiter, and a conservative root drone. All assets are bundled locally so the demo does not depend on runtime NASA API calls or venue Wi-Fi. The interface is built with Vite, React, TypeScript, plain CSS, Vitest, Playwright, and axe-core.

## Super Intelligence disclosure

OpenAI Codex assisted with scaffolding, implementation, tests, UI iteration, and draft documentation. No SI-generated NASA imagery, logos, music files, or voice recordings are used. Runtime audio is generated by the project’s deterministic Tone.js ruleset; NASA images and scientific descriptions are credited and linked in the app.
